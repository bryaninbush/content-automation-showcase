# Showcase Data Boundary

This repository is an architecture showcase, not an operating environment.

- Mother Rain is the only approved demonstration client.
- `client-config.md` retains the Google Workspace binding shape but uses placeholders for Spreadsheet ID, Drive folder, and URL.
- Client schedules, generated drafts, external IDs, credentials, operational task tracking, and all other clients are excluded.
- The `gws` commands show the intended operator boundary. No logged-in session, token, or live Workspace resource is included.
- The image-production guide is a generic template. Client-specific visual preferences and human revision history stay private.
