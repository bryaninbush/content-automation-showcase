# Repository Map

- `clients/Mother Rain/`: approved showcase configuration and brand knowledge.
- `skills/`: operator-facing generation, research, Sheets, and sync workflows.
- `shared/`: reusable platform guidance.
- `templates/`: generic image-production brief template.
- `architecture/database/`: proposed PostgreSQL schema.
- `specs/`: product rules and data-model notes.
- `docs/`: architecture and data-boundary explanations.

The repository deliberately excludes application code, deployment configuration, task tracking, customer schedules, generated output, and external credentials.
