# Draft Generator 草稿生成技能

## 觸發指令
由 Orchestrator 呼叫，或直接使用：
```
/draft [客戶名] [貼文類型] [內容描述]
/draft [客戶名] [貼文類型] [內容描述] --version v2
```

範例：
```
/draft [demo-client] 產品資訊 節慶禮盒的送禮情境 --version v1
/draft [demo-client] 生活知識 甜點冷凍後的回溫方式 --version v2
```

---

## 描述
根據 Google Sheets「文案資料庫」中的 Tags（貼文類型）和 Content（內容描述），結合客戶品牌知識庫，為指定主題產出**單一版本的 IG 文案**。

由 Orchestrator 按主題依序呼叫：
- v1 → v2 → v3（Script_1-3）

確保同一主題的三個版本各自聚焦不同切角。

**核心原則：**
- 一篇貼文 = 一個目的（每個版本聚焦單一目的）
- 三個版本 = 三個不同切角（不是同一個角度的微調，是真正不同的策略）

---

## 輸入參數
- **Client**: 客戶名稱（對應 `clients/` 下的資料夾）
- **Type**: 貼文類型 — `產品服務` / `生活內容` / `服務資訊` / `生活知識` / `互動貼文`（依客戶而異）
- **Content**: 內容描述（來自 Sheets 的 C 欄）
- **Version**: 指定生成版本 — `v1` / `v2` / `v3`（預設 v1）
- **ExistingDrafts**: 已存在的其他版本文案（由 Orchestrator 傳入，用於確保切角差異化）
- **Date**: 預計發布日期（選填，用於季節判斷）
- **Row**: Sheets 行號（由 Orchestrator 傳入，用於寫回）

---

## 工作流程

### Step 1：讀取客戶知識庫
讀取 `clients/[客戶名]/knowledge/` 下的四個檔案：
- `brand-context.md` — 品牌定位與核心價值
- `product-info.md` — 產品資訊與賣點
- `target-audience.md` — 目標受眾特徵
- `writing-style.md` — 寫作風格指南

同時讀取 `shared/platform-guidelines.md` 取得 IG 發文規範。

### Step 2：分析時間因素（如有日期）

| 因素 | 判斷方式 |
|------|---------|
| 月份/季節 | 1-2月冬季、3-5月春季、6-8月夏季、9-11月秋季、12月冬季 |
| 節慶 | 農曆新年、清明、端午、中秋、雙11、聖誕 |
| 特殊時期 | 開學季(9月)、畢業季(6月)、搬家旺季(1,7月) |

### Step 3：設計切角
根據指定的 Version，選擇對應的切角方向：

#### v1-v3（Script_1-3）：固定切角
- **v1（Script_1）**: 偏理性/教育 — 傳遞知識、解決問題、建立專業感
- **v2（Script_2）**: 偏感性/故事 — 情境帶入、生活共鳴、品牌溫度
- **v3（Script_3）**: 偏互動/行動 — 引發討論、促進行動、社群參與

**各類型的切角參考（v1-v3）：**

| 類型 | v1 方向 | v2 方向 | v3 方向 |
|------|---------|---------|---------|
| 產品服務 | 產品規格/使用教學 | 使用情境/生活故事 | 促購/限時/比較 |
| 生活知識/生活內容 | 專業知識科普 | 「你是不是也...」共鳴 | 迷思破解/投票互動 |
| 互動貼文 | 有獎問答/知識挑戰 | 情境投票/經驗分享 | 標註朋友/趣味選擇 |

**如果有 ExistingDrafts（已有的其他版本）：**
- 先讀取已有版本的內容
- 確保新版本的切角與已有版本明顯不同
- 不是換句話說同一件事，而是真正不同的策略

> 以上為預設方向，可根據主題性質靈活調整。重點是三個版本之間要有明顯差異。

### Step 4：撰寫 IG 文案
根據指定版本的切角，撰寫完整的 IG 貼文文案。具體格式、hashtag 策略、品牌尾標等依照客戶 `writing-style.md` 和 `shared/platform-guidelines.md` 執行。

**注意：** 如果客戶的 writing-style.md 有特定 Hashtag 規則（如限制數量），以客戶規則為準，覆蓋 platform-guidelines.md 的通用規則。

### Step 5：品質檢查
生成完成後，自我檢查：
- [ ] 此版本的切角是否與已有版本（ExistingDrafts）明顯不同？
- [ ] 是否聚焦單一目的？
- [ ] 是否遵守客戶 writing-style.md 的用詞規範？
- [ ] 是否符合 IG 平台規範？
- [ ] 是否使用繁體中文（台灣用語）？
- [ ] Hashtags 是否符合客戶的規則？
- [ ] 品牌帶入是否自然（特別是生活內容類）？

## 輸出格式

```markdown
# 貼文草稿

**主題：** [內容描述]
**類型：** [貼文類型]
**版本：** [v1/v2/v3] — [切角名稱，如「知識教學」]
**日期：** [發布日期]
**貼文目的：** [一句話]

---

[完整 IG 貼文文案]

---

## 視覺建議
[建議搭配的圖片方向]
```

---

## Sheets 寫回
Draft Generator 不直接寫回 Sheets。

由 Orchestrator 收集本次新生成的 `{range, values}`，在所有選定草稿生成並存入本地 markdown 後，用一次 `gws sheets spreadsheets values batchUpdate` 批次寫回。批次寫回成功後，Orchestrator 才同步更新 `clients/[客戶名]/content-queue.md`。

生成幾格就只放幾筆 `data` entries，不寫空白覆蓋既有文案。

---

## 使用的工具
- **Read**: 讀取客戶知識庫、平台規範
- **Glob**: 確認檔案結構

## 注意事項
- 各版本之間要有明顯差異，不是換句話說同一件事
- 品牌帶入要自然，生活內容類不要變成硬廣告
- 所有內容必須使用繁體中文，禁止簡體中文用語
- 遵守 writing-style.md 中的 emoji 規範（如客戶要求不使用 emoji 則不用）
