# Research Agent 產業研究技能

## 觸發指令
```
/research [客戶名]
```

範例：
```
/research [demo-client]
/research [client-name]
```

---

## 描述
針對特定客戶的產業進行深度社群媒體行銷研究。根據客戶的產業類型動態決定研究方向，並將結果寫入該客戶的隔離知識庫。

## 使用模型
優先使用 Sonnet 4.6（研究任務的最佳性價比選擇）

---

## 工作流程

### Step 1：讀取客戶設定
讀取 `clients/[客戶名]/client-config.md`，取得：
- 產業類型
- 品牌關鍵字
- 目前啟用的平台

### Step 2：檢查現有知識庫
讀取 `clients/[客戶名]/knowledge/` 下的四個檔案：
- `brand-context.md`
- `product-info.md`
- `target-audience.md`
- `writing-style.md`

檢查 `Last Updated` 時間戳。超過 30 天標記為需要更新。

### Step 3：產業與市場研究
使用 WebSearch 搜尋，**根據客戶產業動態調整搜尋主題**：

**市場趨勢**
- [客戶產業] 台灣市場趨勢與規模
- [客戶產業] D2C / 工廠直營品牌案例
- [客戶產業] 電商銷售趨勢

**競品分析**
- 台灣主要 [客戶產業] 品牌社群經營策略
- 類似定位品牌的成功案例
- 競品的社群內容類型和發文頻率

### Step 4：社群媒體趨勢研究
使用 WebSearch，僅研究客戶啟用的平台：

**IG 趨勢**（如客戶有啟用 IG）
- Instagram [客戶產業] 帳號經營趨勢（台灣）
- IG 上該產業最受歡迎的內容類型

**FB 趨勢**（如客戶有啟用 FB）
- Facebook [客戶產業] 相關社團熱門話題
- FB 上該產業的互動策略

### Step 5：受眾研究
使用 WebSearch，根據 target-audience.md 中已定義的受眾 Persona 進行補充研究。

### Step 6：更新知識庫
將研究結果整合到 `clients/[客戶名]/knowledge/` 的四個檔案中：

**更新原則：**
- 保留原有的基礎架構和品牌資訊
- 新增研究發現的洞察和數據
- 更新 `Last Updated` 時間戳為今天日期
- 標註資訊來源（如果有具體數據）
- 用繁體中文撰寫

**各檔案更新重點：**

| 檔案 | 更新重點 |
|------|---------|
| brand-context.md | 競品分析、市場定位更新、產業趨勢 |
| product-info.md | 產品賣點優化、季節性策略更新 |
| target-audience.md | 受眾行為數據更新、平台使用趨勢 |
| writing-style.md | 社群趨勢反映、hashtag 熱門標籤更新 |

---

## 使用的工具
- **Read**: 讀取客戶設定和現有知識庫
- **WebSearch**: 搜尋市場趨勢、競品策略、受眾行為
- **WebFetch**: 取得特定網頁內容進行深度分析
- **Write**: 更新知識庫檔案
- **Glob**: 確認客戶檔案結構

## 輸出
完成後，向使用者報告：
1. 更新了哪些檔案（含完整路徑）
2. 主要發現摘要（3-5 個重點）
3. 建議的後續行動

## 注意事項
- 研究結果必須基於實際搜尋到的資料，不可憑空捏造數據
- 如果某個搜尋沒有找到有用結果，誠實說明而非編造
- 保持資訊的時效性，標註資料的大約時間
- 所有內容必須使用繁體中文（台灣用語）
- **不同客戶的知識庫完全隔離**，不可跨客戶引用資料
