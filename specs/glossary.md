# Glossary

- Agent: A role-specific coding or management worker with explicit writable boundaries.
- PM: The project manager role responsible for specs, milestones, and audits.
- Spec: A versioned product or engineering rule under `specs/`.
- Spec proposal: A proposed spec change under `pm/spec-proposals/`.
- Organization: Tenant/account boundary.
- Client: Customer brand managed inside an organization.
- Knowledge: Versioned client context used by operators and future generation workflows.
- Job: A content work item queued for a human operator.
- Operator: Human using subscribed Codex/ChatGPT and `gws` to execute content work.
- IAP: Google Identity-Aware Proxy protecting production access.
- gws: CLI used for Google Drive, Docs, and Sheets operations.
